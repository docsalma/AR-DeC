\begin{abstract}
The integration of Augmented Reality (AR) into mobile learning environments holds significant promise for enhancing vocabulary acquisition, yet existing systems typically address only isolated aspects of the learning process. This paper presents a comprehensive UML-driven framework for AR-DeC (Augmented Reality Didactic Companion), a mobile educational application that uniquely integrates four synergistic components: on-device Optical Character Recognition (OCR), an Intelligent Tutoring System (ITS) grounded in Bayesian Knowledge Tracing and Bloom's taxonomy, real-time AR overlays for contextual vocabulary display, and a gamification engine incorporating points, badges, streaks, and quizzes. Employing the Unified Modeling Language (UML), we formalize the pedagogical scenario through four complementary diagrams: a class diagram specifying 15 classes organized across five functional groups, a use case diagram delineating the interactions of three actors (Student, Teacher, System), an activity diagram capturing the dynamic workflow of a learning session, and a sequence diagram illustrating the chronological message flow during a scan-learn-quiz cycle. This dual-perspective modeling approach---combining static structural views with dynamic behavioral views---bridges the gap between pedagogical design intent and technical implementation. The resulting framework provides a reusable architectural blueprint for researchers and developers seeking to design mobile AR-enhanced educational systems that are simultaneously adaptive, engaging, and pedagogically grounded.

\medskip
\noindent\textbf{Keywords:} Augmented Reality, Intelligent Tutoring System, UML Modeling, Gamification, Mobile Learning, OCR, Vocabulary Acquisition, Bayesian Knowledge Tracing
\end{abstract}
