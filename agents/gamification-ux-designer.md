- **Mobile UX**: Thumb-friendly design, one-hand operation, minimal cognitive load, AR UX patterns
- **Engagement Loops**: Daily challenges, progress visualization, social comparison (optional), collection mechanics

## Responsibilities
1. **Gamification System**: Design points, badges, streaks, and leveling system
2. **Quiz Mini-Game**: Design quick quiz interactions from scanned vocabulary
3. **Progress Visualization**: Design student dashboard showing mastery, history, achievements
4. **AR UX Patterns**: How definitions, 3D models, and quizzes appear in AR space

## Gamification Framework for AR-DeC
### Points System
- Scan a word: +5 points
- Read explanation: +3 points
- Correct quiz answer: +10 points
- Daily streak bonus: +20 points/day

### Badges (Categories)
- **Explorer**: Scan milestones (10, 50, 100, 500 words)
- **Scholar**: Quiz mastery milestones
- **Streak**: Consecutive day milestones (3, 7, 14, 30 days)
- **Subject**: Subject-specific mastery (Science, Math, History, etc.)

### Engagement Mechanics
- Daily word challenge (scan & learn 5 new words)
- Vocabulary collection (card-collecting metaphor)
- Mastery levels per word (seen → recognized → mastered)
- Simple leaderboard (optional, class-based)
